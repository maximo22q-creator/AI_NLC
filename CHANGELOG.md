# История версий AI_NLC

Схема версий: `0.0.1` → `0.0.2` → … → `0.0.9` → `0.1.0` → `0.1.1` … (каждый релиз +1 к последней цифре, после 9 — перенос в следующую). Повышение: `python3 bump-version.py "что изменилось"`.

## v0.0.1 — 2026-10-26
- Введена система версий (файл `VERSION`, `APP_VERSION` в интерфейсе, этот журнал, скрипт `bump-version.py`).
- **Исправлен краш «агент вообще не отвечает»**: вызывалась несуществующая функция `renderMarkdown` — скрипт падал с `ReferenceError` при создании ответа и кнопка блокировалась навсегда.
- Скорость/надёжность: таймаут 28с на попытку вместо общего зависания до 90с×3, цепочка каналов (основная модель → быстрая модель → резервный GET), живой секундомер в статусе, ограничение размера статей Википедии (`exchars`), сжатие истории больше не блокирует интерфейс.
- Ранее (до введения версий): память диалога в localStorage со сводкой старой части, понимание намерений (приветствия/загадки не уходят в поиск), умный поиск по ключевым словам с релевантными фрагментами статей, ссылки на источники.
